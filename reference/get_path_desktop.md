# Path to Desktop Folder

Get path to desktop folder of current user and open it.

## Usage

``` r
get_path_desktop(...)

open_desktop()
```

## Arguments

- ...:

  (character) file or folder name on desktop.

## Value

String with path to desktop or path to file or folder on a desktop.

## Examples

``` r
get_path_desktop()
#> /home/runner/Desktop
```
