# Ask before clearing the RStudio console.

Ask before clearing the RStudio console.

## Usage

``` r
rstudio_clear_console_ask()
```

## Value

Invisibly returns `NULL` if RStudio is unavailable or the user says no.

## Examples

``` r
if (FALSE) { # \dontrun{
rstudio_clear_console_ask()
} # }
```
